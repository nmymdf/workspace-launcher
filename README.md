# 工作清單啟動器 v0.8

作者：ArchieKUO

一次開啟一組 App／資料夾／檔案／網址，並把視窗整齊排在指定螢幕上，不會再蓋來蓋去。

## 使用重點
- 左邊是清單，右邊是項目表。點一下儲存格開始輸入；Enter 或 Tab 跳下一格；下拉要再點一下或按 ↓ 才打開。
- 最下面的空白列：填好路徑就自動新增；路徑有錯會標紅、不會存。
- 把檔案、資料夾、程式從檔案總管直接拖進項目表就會新增。
- 拖左邊把手可調整順序（Alt+↑↓ 也可以）；把項目拖到左邊的清單上＝搬移，按住 Ctrl＝複製。
- 預覽：拖格子互換位置、拖灰色把手調大小；「還原自動平分」回到整齊平分。
- 「開啟於」選螢幕1 或螢幕2；個別項目的「螢幕」欄可以例外。
- 「全部開啟並排列」＝開啟勾選項目並排好；「整理現有視窗」＝只排已經開著的視窗。
- 設定裡可選「開機時自動啟動」（預設關閉），並指定開機後要自動執行哪一份清單。

## 已知限制（第一版）
- 網址每次按「全部開啟並排列」都會開新的瀏覽器視窗；「整理現有視窗」不處理網址。
- 以系統管理員身分執行的程式，視窗無法被一般權限的工具移動。
- 部分 Microsoft Store 版 App 抓不到視窗，只會開啟、不排版。

## 雲端編譯 exe
推到 GitHub 後，Actions 會自動編譯，exe 放在 `exe` 分支（檔名帶版本號）。
也可以在有 Python 3.12 的電腦雙擊 `build.bat`。

## v0.2 新增
- 捷徑（.lnk）自動判斷：指到資料夾算資料夾、指到網址算網址；用項目名稱找視窗（LINE 等 App 直接加成 App 項目即可）。
- 視窗晚出現（最多等 60 秒）也會排進去。
- 新類型：YouTube最新（頻道最新影片）、音樂資料夾（用預設播放器播放，不參與排版）。
- 跟隨 Windows 深色／淺色與強調色；新圖示。

## v0.3 新增
- 方框只代表「執行」；刪除改成右鍵「刪除此項…」（一次一項、先確認），清單也可右鍵重新命名／刪除。
- 右鍵可把項目「移到／複製到」其他清單。
- 工具列新增「顯示桌面」（把其他視窗收起來，方便從桌面拖捷徑；再按一次還原）。
- 視窗拖多小都能用，畫面依大小自動收；拿掉精簡模式。
- 視窗搬完會再檢查，位置或大小被程式改回去就重搬。

## v0.4 新增
- 工具列「全部關閉」：只關這份清單裡打勾、而且是本工具自己開出來的視窗，先確認；有程式問要不要存檔就會留著並告訴你，全部關完才關閉本工具。
- 再按「全部開啟並排列」不會重複開：網址／YouTube 的瀏覽器視窗、音樂播放器還開著就沿用（被關掉才重開）。
- 音樂資料夾改用「播放」動作開啟，讓播放器自動開始播放（不支援時退回一般開啟）。

## v0.5 新增
- 音樂播放器固定放螢幕2 右下角（小視窗，不佔格子）；拖進資料夾時，大多是音樂檔就自動當音樂資料夾；右鍵可「改成音樂資料夾／一般資料夾」。
- 瀏覽器視窗記在設定檔，重開工具再按也不會重複開網址／YouTube。
- 「全部關閉」改成直接找這份清單裡打勾的項目的視窗來關（不論是誰開的）；音樂播放器不關。
- 紀錄檔 `%APPDATA%\WorkspaceLauncher\log.txt`（設定頁可開資料夾）；狀態列文字太長時，滑鼠移上去看全文。

## v0.6 新增
- 每列最右邊的 ► 按鈕、右鍵「只開啟此項」：只開啟單一項目（不管有沒有打勾），放滿整個螢幕，其他項目不動。

## v0.7 新增
- 只能開一份：已經在執行時，再點一次只會把原來那份叫到最前面。
- 狀態列右邊固定顯示「已儲存 時:分:秒」；空白列只填名稱或類型時，提醒還沒填路徑。
- 設定新增「音樂資料夾：逐首開啟」，媒體播放器出現「沒有存取檔案的權限」時用；也可以到媒體播放器「設定 → 媒體庫」把音樂資料夾加進去。

## v0.8 新增
- 音樂資料夾改用 VLC 播放（預設 `C:\Program Files\VideoLAN\VLC\vlc.exe`，可在設定改位置），連續播放整個資料夾，不再有媒體播放器的「沒有存取檔案的權限」問題；取消勾選或找不到 VLC 時，用預設播放器的「開啟」動作開一首（等於點兩下）。
- VLC 視窗一樣放螢幕2 右下角，不佔格子。
